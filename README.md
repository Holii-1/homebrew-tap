# Homebrew Tap for Yasno Widget

Офіційний Homebrew Tap для [Yasno Widget for macOS](https://github.com/Holii-1/YasnoWidget) — нативного віджета графіків відключень Yasno / ДТЕК із живими датчиками СвітлоБот та Healthchecks.io.

## 📦 Встановлення

Встановлення однією командою:

```bash
brew install Holii-1/tap/yasno
```

Або класично з підключенням тапу:

```bash
brew tap Holii-1/tap
brew install yasno
```

## 🔄 Оновлення

```bash
brew upgrade yasno
```

## 🗑 Повне видалення

```bash
brew uninstall --zap yasno
```
